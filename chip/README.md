# chip

rgl filter to hash filepaths and identifiers.

## Settings

Category names are defined by the string enum in [categories.ts](categories.ts). Omitted categories default to `true`; use `false` to disable a target's definitions or file moves, references, and associated scripting helper together.

```json
{
	"seed": 1234567890,
	"namespace": "pg_test",
	"namespacePath": "pg/test",
	"categories": {
		"lootTables": false,
		"geometry": false,
		"textureAtlasKeys": true
	}
}
```

| Category                     | Controls                                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `lootTables`                 | Loot file paths, JSON references including trading functions and processors, and the loot scripting helper.                     |
| `tradeTables`                | Trade file paths and entity trade references.                                                                                   |
| `textures`                   | Image and texture-set paths, PBR image names, JSON texture paths including water caustics, and the UI texture scripting helper. |
| `audioPaths`                 | Audio file paths and sound-definition file references.                                                                          |
| `textureAtlasKeys`           | Item/terrain atlas keys and their JSON references.                                                                              |
| `geometry`                   | Geometry identifiers and their JSON references.                                                                                 |
| `animations`                 | BP animation identifiers and behavior-entity description references.                                                            |
| `animationControllers`       | BP animation-controller identifiers and behavior-entity description references.                                                 |
| `animationAliases`           | BP entity animation alias keys, `scripts/animate`, and controller-state animation references.                                   |
| `controllerStates`           | BP controller state names, initial states, and transition destinations.                                                         |
| `clientAnimations`           | RP animation identifiers, client-description references, and the `Entity.playAnimation()` scripting helper.                     |
| `clientAnimationControllers` | RP animation-controller identifiers and client-description references.                                                          |
| `clientControllerStates`     | RP controller state names, initial states, and transition destinations.                                                         |
| `renderControllers`          | Render-controller identifiers and client-description references.                                                                |
| `blockCulling`               | Block-culling identifiers and block geometry references.                                                                        |
| `componentGroups`            | Entity component-group keys and event references.                                                                               |
| `water`                      | RP water identifiers and client-biome water references.                                                                         |

## Implemented

`*` matches an object key, `[#]` an array element, and `**` any depth.

- **Entity components**: `minecraft:entity/components/` and `minecraft:entity/component_groups/*/`.
- **Block components**: `minecraft:block/components/` and `minecraft:block/permutations/[#]/components/`.
- **Client descriptions**: `minecraft:client_entity/description/` and `minecraft:attachable/description/`.
- **Behavior entity descriptions**: `minecraft:entity/description/`.

## Notes

- Hashes use seeded [MurmurHash3 x86_32](https://github.com/aappleby/smhasher/blob/master/src/MurmurHash3.cpp) over UTF-8, formatted as eight lowercase hex digits.
- `CustomForm.image()` only support static string paths. `ObservableString` sources are unchanged.
- Not every reference is rewritten. Commands and arbitrary script string literals are not rewritten; runtime support is limited to the listed scripting hooks.
- For paths, chip moves into root directory (e.g `textures/foo/bar/entity/myentity.png` -> `textures/foo/bar/80d8c886.png` with seed `"1"`). If `textures/foo/bar/entity/` is an empty directory after hash processing, it will be removed.
